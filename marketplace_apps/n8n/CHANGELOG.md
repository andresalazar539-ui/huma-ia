# Changelog

## 0.1.0

- HUMA IA OAuth2 API credential (OAuth 2.0 with PKCE).
- HUMA IA Trigger: New Lead, Lead Qualified, Appointment Confirmed, Payment Approved, Contract Signed, Contract Refused.
- Trigger deliveries are verified with the HMAC-SHA256 signature sent by HUMA IA (HTTP 401 on mismatch).
- HUMA IA node, Conversation resource: Add Note, Get, Hand Off, Move to Stage, Search, Send Message.
